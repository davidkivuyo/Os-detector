# Detects user's OS
With the OS detector you can detect user's current Operating System using javascript ``navigator`` object.

* See your currently used OS 👉 [osdetect.net](https://davidkivuyo.github.io/Os-detector)

# Import the codes
import the codes in your project files and start using it.

you can run it using live server(the vscode extension) or with any build tool such as vite, parcel
